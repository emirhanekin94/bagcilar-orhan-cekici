## 3. Zorunlu Negatif Anahtar Kelimeler (Bütçe Koruma)

### A) `goztepe-oto-cekici.html` Reklam Grubu İçin Zorunlu Negatifler
Anadolu Yakası Kadıköy Göztepe aramalarını kesmek için **reklam grubu düzeyinde** kesinlikle negatifleyin:
- `kadıköy`, `anadolu yakası`, `anadolu`, `göztepe köprüsü`, `köprü`, `merdivenköy`, `sahrayıcedit`, `caddebostan`, `erenköy`, `suadiye`, `kozyatağı`, `üsküdar`

### B) Kampanya Genel Negatif Listesi
- **İkinci El / Satılık / Kiralık:** `satılık`, `kiralık`, `ikinci el`, `sahibinden`, `fiyatı ne kadar araba`, `çıkma`, `hurda`, `pert`, `oyuncak`, `akülü araba`
- **İş / Ehliyet / Resmi:** `iş ilanı`, `şoför ilanı`, `maaş`, `eleman`, `operatör belgesi`, `ehliyet`, `belediye`, `trafik vakfı`, `yediemin telefonu`, `çekilen araç sorgulama`, `aracım nereye çekildi`
- **Hizmet Dışı İlçeler / Bölgeler (hedeflenmiyorsa):** `ankara`, `izmir`, `bursa`, `antalya`, `kocaeli`, `pendik`, `kartal`, `maltepe`, `tuzla`, `üsküdar`, `kadıköy`, `beykoz`, `çekmeköy`, `sancaktepe`, `sultanbeyli`, `şile`

## 4. Reklama Çıkmadan Önce 3 Adımlık Aktivasyon

Marka adı, domain ve Google Ads kimlikleriniz hazır olduğunda yalnızca şu 3 adımı uygulayın:

1. [data/business.js](file:///c:/Users/emirh/Desktop/iş/bagcilar-orhan-cekici/data/business.js) dosyasını açıp şunları doldurun:
   - `SITE_URL` → gerçek domain (`https://...`)
   - `BUSINESS.name`, `shortName`, `legalName` → gerçek marka adı
   - `BUSINESS.email` → kurumsal e-posta adresi (İletişim ve KVKK sayfasına otomatik basılır)
   - `BUSINESS.analytics.ga4Id` → `G-...`
   - `BUSINESS.analytics.adsId` → `AW-...`
   - `BUSINESS.analytics.adsCallConversion` → `AW-.../...` *(Birincil Dönüşüm: Telefon Tıklamaları)*
   - *(Opsiyonel)* `BUSINESS.analytics.adsWhatsappConversion` → `AW-.../...` *(İkincil/Gözlem Dönüşüm)*
2. Terminalde tüm siteyi tek komutla derleyin:
   ```powershell
   npm run build
   ```
3. Canlıya alın ve `?gclid=test` parametresiyle siteyi açıp Network sekmesinden `gtag/js` ve `tel:` tıklamasında conversion isteğinin gittiğini doğrulayın.
